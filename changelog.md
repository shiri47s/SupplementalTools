# 🗓️ Changelog

## 📦 Version 3.0.0

### ✨ What's New

- Updated for Minecraft 26.2. The NeoForge build now requires it specifically.

### 🔧 Fixes

- Durable totems no longer save you from `/kill` or the void.
- Durable items now show the correct number of uses left.
- An upgraded durable totem is used before a plain one.
- Durable torches now trigger sculk sensors when placed.
- A non-placeable item in your off hand no longer blocks the durable torch.
- The Quartz set's glow no longer flickers.
- Effects given with `/effect` survive rejoining a world.
- A number of other small issues.

### ⚠️ Known Limitation

- On NeoForge, a mod loading warning screen appears before the title screen. Click Continue to proceed.

---
💡 *As always, back up your worlds before updating. Happy crafting!*
